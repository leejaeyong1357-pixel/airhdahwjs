# 현장밀착점검 보고서 (일일현장안전점검) — 월별 자료 내려받기 페이지

KOI 에 올리기엔 파일이 커서, 링크 한 줄로 실장님들이 들어와 월별 파일을 내려받게 하는 페이지입니다.
다른 폴더(blockcraft · edu-survey · kpi)와는 별개입니다. Node.js 만 있으면 되고 설치할 것은 없습니다.

## 켜기
- Windows: `pt-report\start.cmd` 더블클릭 (또는 `cd pt-report` → `node server.js`)
- 포트: **2822** (바꾸려면 `set PORT=다른번호` 후 실행)
- 보는 주소: `http://<이 PC IP>:2822/` — 켜면 창에 주소가 나옵니다. 이 주소를 KOI 에 링크로 올리면 됩니다.
- 다른 PC 에서 안 열리면 방화벽에서 2822 포트를 허용하세요.

## 환경설정 (관리자)
- 보는 화면 **맨 아래 오른쪽 톱니바퀴** → `http://<이 PC>:2822/admin`
- 처음 비밀번호: 서버를 켤 때 창에 나오고 `pt-report/data/admin-password.txt` 에도 있습니다. 들어가서 꼭 바꾸세요.
- 바꿀 수 있는 것
  - 모든 문구: 부서명 · 제목 · 작은 제목 · 인사말(파란 이름 포함) · 안내 본문 · 자료 칸 제목/안내 · 버튼 글자 · 아래 안내 줄(추가 · 삭제 · 순서) · 브라우저 탭 제목 · 그림 속 안전모/점검표 글자
  - 자료 칸: 제목(1월 …) · 칸에 보일 파일 이름 · 순서(▲▼ 또는 끌어서) · 칸 추가/삭제 · 한 줄에 칸 수(1~8)
  - 파일: 칸마다 [파일 올리기] 또는 파일을 칸에 끌어다 놓기 — 큰 파일(기본 최대 2GB)도 진행 막대와 함께 올라갑니다. 다운로드 횟수도 보입니다.
  - 머리글 오른쪽 그림을 사진으로 바꾸기 / 기본 그림으로 되돌리기
  - 관리자 비밀번호 바꾸기, 문구를 처음 상태로 되돌리기
- 저장하면 보는 화면에 바로 반영됩니다 (아래 미리보기로 확인).

## 저장 위치
- 설정: `pt-report/data/site.json` · 올린 파일: `pt-report/data/files/` (git 에 올라가지 않음 — 이 PC 에만)
- 내려받을 때 파일 이름은 “1월 일일현장안전점검.pptx” 처럼 칸 제목이 앞에 붙습니다.
- 최대 파일 크기를 바꾸려면 `set MAX_UPLOAD_MB=5000` 후 실행.
