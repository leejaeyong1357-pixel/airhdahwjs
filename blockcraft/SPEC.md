# 테크젠 크래프트 — 설계서 (v2: 서바이벌)

> 목표: **브라우저로 접속하는 "진짜 마인크래프트 같은" 사내 멀티플레이 게임.**
> 설치 없음 · 서버는 Node.js 하나 · 원작 코드/그림 사용 금지(텍스처 · 모델은 코드로 직접 그림).

## 1. 계정 · 접속
- 첫 화면: **[로그인] / [가입하기]** 탭. 아이디(한글·영문·숫자 2~12자) + 비밀번호(4자 이상).
- 비밀번호는 서버에 scrypt 해시로만 저장. 로그인하면 토큰을 브라우저에 저장 → 다음부터 자동 로그인.
- **계정마다 진행 상황 저장**: 위치 · 시선 · 체력 · 배고픔 · 인벤토리 · 게임 모드. 다른 PC 에서 로그인해도 이어서 한다.
- 같은 계정 동시 접속 금지. **처음 가입한 계정 = 관리자.**

## 2. 월드
- 시드로 만드는 무한 지형: 평원 · 숲 · 바다 · 모래사장 · 산 · 눈, **동굴**, 광석(석탄 · 철 · **다이아몬드**), 기반암.
- **모두 같은 스폰 지점.** 새 계정 · 죽은 뒤 부활은 항상 월드 스폰.
- 사람이 바꾼 블록만 저장(`data/world.json`), 지형은 시드로 다시 만든다.
- **낮 · 밤**: 하루 20분(마크와 동일, 낮 10분 · 노을 · 밤 7분 · 새벽). 서버 시간 기준이라 모두 같은 시간.
  해 · 달 · 별 · 구름, 하늘 · 안개 색 변화. 밤에는 어둡다.
- **빛**: 하늘빛(지붕 · 동굴 안은 어두움) + **횃불 빛**(14칸 퍼짐) + 모서리 그림자(AO).

## 3. 플레이어 (서바이벌)
- **처음엔 빈손.** 나무를 맨손으로 캐서 시작.
- 체력 하트 10칸 · 배고픔 10칸 · 물속 공기 방울.
  - 낙하 데미지(3칸 초과), 익사, 굶주림(배고픔 0), 배고픔 18 이상이면 체력 회복.
  - 달리기 · 점프는 배고픔을 더 빨리 줄인다. 배고픔 6 이하면 달리기 불가.
- 죽으면 "죽었습니다!" 화면 → [부활] → 가진 아이템은 그 자리에 떨어지고 스폰에서 다시 시작.
- **1인칭 손**이 보이고, 들고 있는 블록 · 도구가 손에 보인다. 캘 때 · 칠 때 · 놓을 때 휘두르는 동작, 걸을 때 흔들림.
- 크리에이티브 모드(관리자 `/gamemode creative`): 즉시 부수기, 무한 블록, 날기, 데미지 없음.

## 4. 블록 캐기 · 놓기
- **왼쪽 버튼을 누르고 있어야 캐진다.** 블록마다 단단함이 다르고, 금이 가는 모습(10단계)이 보인다. 손을 떼면 처음부터.
- 알맞은 도구가 빠르다(곡괭이: 돌 · 광석, 도끼: 나무, 삽: 흙 · 모래). 등급: 나무 < 돌 < 철 < 다이아.
- 돌 · 광석은 **곡괭이가 있어야 아이템이 나온다.** 철광석은 돌 곡괭이 이상, 다이아는 철 곡괭이 이상.
- 캐면 부서지는 조각이 튀고, **아이템이 바닥에 떨어져 빙글빙글** → 가까이 가면 주워진다.
  잔디 → 흙, 돌 → 조약돌, 석탄광석 → 석탄, 다이아광석 → 다이아몬드, 나뭇잎 → 가끔 사과, 유리 → 없음.
- 도구는 내구도가 있어 쓰면 닳고 부서진다.
- 오른쪽 버튼: 블록 놓기(손에 든 개수 1 감소) · 작업대/화로 열기 · 음식 먹기(누르고 있기).
- Q: 들고 있는 아이템 1개 버리기.

## 5. 인벤토리 · 조합
- **E 또는 Tab**: 인벤토리 화면 — **내 캐릭터 모습**(마우스를 따라 고개를 돌림) + **2x2 조합칸** + 36칸(단축칸 9 + 가방 27).
- 마크와 같은 클릭: 왼쪽 클릭 집기/놓기/바꾸기/합치기, 오른쪽 클릭 반 나누기/1개 놓기, Shift+클릭 빠른 이동, 조합 결과 Shift+클릭 최대 제작.
- **작업대**(3x3 조합): 오른쪽 클릭으로 열기.
- **화로**: 재료 + 연료 → 시간이 지나면 결과물. 화로 내용은 서버에 저장되어 모두 같은 화로를 본다.
- 조합법(마크와 같은 모양): 나무→판자4, 판자2(세로)→막대기4, 판자4→작업대, 석탄+막대기→횃불4, 조약돌8→화로,
  곡괭이 · 도끼 · 삽 · 검 × (나무 · 돌 · 철 · 다이아).
- 굽기: 철광석→철괴, 모래→유리, 조약돌→돌, 날고기→구운 고기, 나무→숯(석탄). 연료: 석탄 · 나무 · 판자 · 막대기.

## 6. 몹
- 서버가 움직이고 모두에게 똑같이 보인다.
- **낮**: 돼지 · 소 · 양 · 닭 — 풀밭에 나타나 돌아다니고, 맞으면 도망간다.
  드롭: 돼지고기 · 소고기 · 양털 · 닭고기 · 깃털.
- **밤**: 좀비(쫓아와서 때림, 해가 뜨면 불타 사라짐) · 크리퍼(다가와서 치익… 폭발, 블록을 부수고 큰 데미지).
  드롭: 썩은 살점 · 화약.
- 때리면 넉백 · 빨갛게 번쩍, 무기에 따라 데미지(맨손 1 · 검 4~7).

## 7. 화면 · 조작
| 키 | 동작 |
|---|---|
| WASD · 마우스 | 이동 · 둘러보기 |
| Space / Shift | 점프 / 달리기 (날 때 위 / 아래) |
| 왼쪽 (누르고 있기) | 캐기 · 공격 |
| 오른쪽 | 놓기 · 열기 · 먹기 |
| 1~9 · 휠 | 단축칸 |
| E · Tab | 인벤토리 · 조합 · 내 모습 |
| Q | 버리기 |
| T · / | 채팅 · 명령어 |
| F3 | 좌표 · FPS |
| Esc | 일시정지 (접속자 목록 · 로그아웃) |

관리자 명령: `/gamemode survival|creative [이름]`, `/time day|night`, `/give 아이템 [개수]`, `/tp 이름`.
모두: `/spawn`(스폰으로), `/kill`(부활).

## 8. 구조
```
blockcraft/
  server.js            HTTP(화면 · 가입/로그인 API) + 웹소켓 + 저장
  server/              accounts · world(서버 쪽 지형) · mobs · items(떨어진 아이템) · furnace
  shared/              blocks · items · recipes · worldgen (서버와 브라우저 공용)
  public/              index.html · style.css · main.js · textures · render/* · ui/*
  data/                world.json · accounts.json (git 제외)
```
