# TECZEN WORLD — 설계서 (v2)

> 목표: **브라우저로 접속하는 "진짜 마인크래프트 같은" 사내 멀티플레이 3D 복셀 샌드박스.**
> 원작의 코드 · 그림 · 소리 · 캐릭터는 쓰지 않는다 — 텍스처 · 모델 · 소리는 코드로 직접 만들고, 몹은 이 게임만의 디자인.
>
> 요구가 겹치면 **사용자가 직접 말한 것이 우선**, 그다음이 요구사항 문서(TECZEN WORLD 프롬프트).
> - 첫 화면은 사용자가 준 그림과 똑같이 (게임 시작 · 로그인 · 설정 · 종료). 싱글 · 멀티 · 이어하기는 '게임 시작' 안에서 고른다.
> - Tab 과 E 모두 인벤토리(조합 + 내 모습). 달리기 Ctrl(또는 W 두 번), 웅크리기 Shift.

## 1. 계정 · 접속
- 아이디(한글 · 영문 · 숫자 2~12자) + 비밀번호(4자 이상). scrypt 해시 저장, 토큰 자동 로그인(180일), 로그인 실패 5분 10회 제한.
- 계정마다 월드별 진행 상황 저장(위치 · 시선 · 인벤토리 · 방어구 · 체력 · 배고픔 · 경험치 · 게임 모드). 같은 계정 새 접속 시 이전 접속 끊음.
- 처음 가입한 계정 = 관리자.

## 2. 월드
- 멀티플레이 월드 1개 + 사람마다 싱글플레이 월드. 같은 시드 = 같은 지형, 사람이 바꾼 블록만 저장.
- 바이옴(평원 · 숲 · 자작나무숲 · 침엽수림 · 사막 · 산), 바다 · 강 · 호수 · 해변, 동굴 · 협곡 · 용암(y≤10), 광석, 나무 4종류, 풀 · 꽃 · 선인장 · 마른 덤불.
- 모두 같은 스폰(숲 가장자리 풀밭). 하루 20분. 날씨(맑음 · 비/눈 · 천둥) 자동 변화.
- 빛: 하늘빛 BFS + 횃불빛 BFS(15칸) + AO, 셰이더에서 낮밤 밝기 반영.

## 3. 플레이어
- 서바이벌: 체력 20 · 배고픔 20(포화도 · 소모도) · 공기 · 방어력 · 경험치/레벨. 낙하(물 착지 무피해) · 익사 · 용암 · 선인장 · 굶주림 · 공격 피해, 자연 회복.
- 죽음 → 화면 → 부활(스폰). 아이템 떨어뜨림(규칙 keepInventory).
- 1인칭 팔 · 든 아이템(입체 픽셀 모델) · 걷기/달리기/점프/캐기/공격/먹기 동작. F5 3인칭.
- 크리에이티브: 즉시 부수기 · 무한 블록 · 날기 · 무피해 · 모든 아이템 목록.

## 4. 캐기 · 놓기
- 누르고 있어야 캐짐, 금 10단계, 조각 · 소리, 도구 배율 · 등급, 내구도, 드롭 아이템이 바닥에서 돌며 다가가면 주워짐.
- 서버가 캐는 시간 · 거리 · 손에 든 블록을 확인. 놓을 자리 미리보기, 몸과 겹치면 못 놓음.

## 5. 인벤토리 · 제작
- 36칸 + 방어구 4칸 + 2x2/3x3 조합 + 결과. 클릭 · 오른쪽 · Shift · 끌어 나누기 · 숫자키 · 버리기.
- 모든 조작은 `shared/invops.js` 규칙으로 브라우저 · 서버가 똑같이 계산(요약값으로 비교 → 다르면 서버가 정답 전송).
- 화로(재료 · 연료 · 결과, 10초/개, 연료 시간, 경험치) · 상자(27칸) — 서버 저장.

## 6. 몹
- 돼지 · 소 · 양 · 닭(초식), 멧돼지(중립), 좀비(근접), 해골 궁수(원거리 화살), 폭탄몬(폭발).
- 상태 기반 AI + 시야 판정 + A* 길찾기(한 칸 오르기 · 세 칸 내려가기), 낭떠러지 · 물 · 용암 회피, 햇빛에 탐, 낙하 피해.
- 대기 · 이동 · 공격 · 피격(빨강 + 넉백) · 사망(쓰러짐 + 연기) 애니메이션, 드롭 · 경험치.

## 7. 네트워크
- 웹소켓(직접 구현). 플레이어 10Hz 이동 + 보간, 몹 · 아이템 · 화살은 서버가 20Hz 로 움직이고 관심 영역(80칸) 안만 10Hz 로 전송.

## 8. 저장
- 원자적 쓰기(임시 파일 → 바꿔치기), 30초 자동 저장, 10분 백업 24개, 손상 시 백업 복구.
