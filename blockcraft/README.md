# 테크젠 크래프트 (사내 멀티플레이 블록 게임)

브라우저(크롬 · 엣지)로 접속하는 마인크래프트 스타일 게임입니다. **설치 없이** 주소만 열면 됩니다.
AX LAB 사이트와 상관없는 별도 폴더이고, 서버는 **Node.js 하나로** 돌아갑니다. (npm 설치 없음)

- 무한 지형: 잔디 · 숲 · 바다 · 모래사장 · 산 · 눈 · 동굴 대신 광석(석탄 · 철)
- 블록 26가지: 흙 · 돌 · 나무 · 판자 · 유리 · 벽돌 · 양털 6색 · 금 · 책장 · 호박 · 테크젠 블록 …
- 멀티플레이: 서로 캐릭터와 닉네임이 보이고, 블록을 부수고 놓으면 모두에게 바로 반영
- 채팅, 접속자 목록, 날기, 수영
- 월드 자동 저장 (30초마다 · 서버 끌 때) — `data\world.json`
- 마인크래프트 원작 코드 · 그림을 쓰지 않음 (텍스처는 코드로 직접 그림, 3D 는 three.js · MIT)

## 서버 켜기 (cmd)

```
cd C:\Users\TECZ\airhdahwjs
git pull
cd blockcraft
start.cmd
```

화면에 나오는 주소로 접속합니다.

```
  이 PC 에서:     http://localhost:25565
  직원 접속 주소: http://10.208.1.212:25565
```

끄기: 서버 창에서 **Ctrl+C** (월드 저장 후 꺼짐)

### 다른 PC 에서 접속이 안 되면

`firewall.cmd` 를 **마우스 오른쪽 클릭 → 관리자 권한으로 실행** (TCP 25565 열기).
회사 정책으로 막히면 전산팀에 **"TCP 25565 수신 허용"** 을 요청하세요.
포트를 바꾸려면 `start.cmd` 의 `PORT` 를 고칩니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD · 마우스 | 이동 · 둘러보기 |
| Space / Shift | 점프 / 달리기 (날 때는 위 / 아래) |
| 왼쪽 클릭 / 오른쪽 클릭 | 블록 부수기 / 놓기 (누르고 있으면 연속) |
| 휠 클릭 | 보고 있는 블록 집기 |
| 1~9 · 휠 | 단축칸 고르기 |
| E | 블록 목록 (눌러서 단축칸에 넣기) |
| F 또는 Space 두 번 | 날기 켜기 / 끄기 |
| T · Enter | 채팅 (`/spawn` 처음 위치로) |
| Tab | 접속자 목록 |
| F3 | 좌표 · FPS |
| Esc | 마우스 풀기 (일시정지) |

## 월드 관리

- 월드 = 시드(지형) + 사람이 바꾼 블록. `data\world.json` 한 파일입니다.
- 백업: 서버를 끄고 `data\world.json` 을 복사
- 새 월드로 시작: 서버를 끄고 `data\world.json` 을 지운 뒤 다시 켜기 (새 지형)
