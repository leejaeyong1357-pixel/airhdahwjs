# TECZEN WORLD (테크젠 크래프트 v2)

브라우저로 접속하는 사내 3D 복셀 샌드박스 게임입니다. 설치 프로그램 없이 크롬·엣지로 들어와서 같이 캐고, 짓고, 만들고, 싸웁니다.
서버는 **Node.js 하나**로 돌아가며 npm 설치가 필요 없습니다. 그림·소리·캐릭터는 모두 코드로 직접 만들었습니다(외부 에셋 없음).

## 실행

### 서버 켜기 (Windows)
1. [Node.js](https://nodejs.org) LTS 설치 (처음 한 번)
2. `blockcraft\start.cmd` 더블클릭 → 창에 **직원 접속 주소**가 나옵니다 (예: `http://10.208.1.212:25565`)
3. 다른 PC 에서 접속이 안 되면 `firewall.cmd` 를 **관리자 권한으로 실행** (TCP 25565 허용)

```bash
node server.js                 # 기본 포트 25565
PORT=8080 node server.js       # 포트 바꾸기
```

### 접속하기
1. 브라우저로 접속 주소 열기 → 첫 화면
2. **로그인** → [가입하기] 탭에서 아이디·비밀번호 만들기
   - 관리자는 `blockcraft/config.json` 의 `admins` 에 적힌 아이디만 됩니다 (기본: `이재용`). 새로 가입한 직원은 관리자가 아닙니다.
3. **게임 시작** → `멀티플레이`(회사 서버 월드, 모두 같이) 또는 `싱글플레이`(나만의 월드) / 다음부터는 `이어하기`
4. 한 번 로그인하면 그 PC 에서는 자동 로그인됩니다. 다른 PC 에서 같은 계정으로 들어와도 진행 상황이 이어집니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD · 마우스 | 이동 · 둘러보기 |
| Space | 점프 |
| Ctrl · W 두 번 | 달리기 |
| Shift | 웅크리기 (낭떠러지에서 안 떨어짐) |
| 왼쪽 버튼 (꾹) | 캐기 — 금이 가다가 부서짐 · 공격 |
| 오른쪽 버튼 | 블록 놓기 · 작업대/상자/화로 열기 · 음식 먹기(꾹) |
| E | 인벤토리 (내 모습 · 방어구 · 2x2 조합) |
| Tab | 점수판 (킬 · 데스 · 어시스트) · 닉네임 변경 |
| M | 지도 — 리스폰 지점(빨간 깃발) · 내 위치(화살표) · 다른 사람, 리스폰까지 거리 · 방향. 휠 확대, 끌어서 이동. 죽었을 때도 볼 수 있음 |
| T | 춤 — "L을 가져가~" (머리 위에 대사, 움직이면 멈춤) |
| 1~9 · 휠 | 단축칸 (인벤토리에서 칸 위에 두고 누르면 그 칸과 바꾸기) |
| Q (Ctrl+Q) | 1개 (묶음) 버리기 |
| 총: 왼쪽 · 오른쪽 · R | 쏘기(M16 은 누르고 있으면 연사) · 조준(저격총은 스코프 줌) · 재장전 |
| 칼: 왼쪽 · 꾹 | 클릭하면 베기(좌우 번갈아), 누르고 있으면 계속 찌르기 |
| 수류탄: 왼쪽 꾹 → 떼기 | 누르면 핀을 뽑고 힘 게이지가 참 — 바로 떼면 눈앞, 오래 당길수록 멀리. 당기다 무기 바꾸면 취소 |
| Enter · / | 채팅 · 명령어 |
| F5 · F3 · F1 | 시점 바꾸기(1인칭 → 3인칭 뒤 → 3인칭 앞) · 좌표/FPS · 화면 정보 숨기기 |
| Esc | 일시정지 (계속하기 · 설정 · 첫 화면) |

인벤토리: 왼쪽 클릭 집기/놓기/합치기/바꾸기, 오른쪽 클릭 반 집기/1개 놓기, Shift+클릭 빠른 이동, **들고 끌기**로 여러 칸에 나눠 놓기, 창 바깥 클릭으로 버리기.

## 게임 내용

- **월드**: 평원 · 숲 · 자작나무숲 · 눈 덮인 침엽수림 · 사막(선인장) · 산 · 바다 · 강 · 호수 · 해변, 동굴 · 협곡 · 용암 호수, 석탄 · 철 · 다이아몬드 · 흑요석. 같은 시드면 같은 지형.
- **빛**: 하늘빛(지붕 · 동굴 안은 어두움) + 횃불 빛 + 모서리 그림자, 해 · 달 · 별 · 구름, 일출 · 일몰, 비 · 눈 · 천둥(날씨), 캐릭터 · 몹 발밑 그림자.
- **하루 20분**: 낮 10분 · 밤 7분. 서버 시간이라 모두 같은 시간.
- **서바이벌**: 체력 · 배고픔 · 방어력 · 경험치 · 공기(물속). 낙하(물에 떨어지면 피해 없음) · 익사 · 용암 · 선인장 · 굶주림 피해, 배부르면 회복. 죽으면 아이템을 떨어뜨리고 스폰에서 부활 (`/gamerule keepInventory true` 로 유지 가능).
- **채굴**: 블록마다 단단함이 달라 시간이 걸리고 금 간 모습 10단계 · 조각 · 소리. 알맞은 도구가 빠르고(곡괭이: 돌 · 광석, 도끼: 나무, 삽: 흙 · 모래), 곡괭이 등급이 맞아야 광석이 나옵니다. 도구 내구도.
- **제작**: 2x2(인벤토리) · 3x3(작업대). 판자 · 막대기 · 작업대 · 횃불 · 화로 · 상자 · 사암 · 벽돌 · 책장 · 화살, 나무/돌/철/다이아 곡괭이 · 도끼 · 삽 · 검, 가죽/철/다이아 방어구, 양털 염색.
- **화로**: 재료 · 연료 · 결과 칸, 실제 시간으로 굽기(10초/개), 남은 연료 표시, 창을 닫아도 서버에서 계속 구움, 경험치.
- **상자**: 27칸, 서버 저장, 여럿이 같이 씀.
- **몹** (모두 이 게임만의 디자인)
  - 낮: 돼지 · 소 · 양(색 여러 가지) · 닭 — 맞으면 도망
  - 멧돼지: 평소엔 얌전, 때리면 들이받음
  - 밤 · 동굴: 좀비(햇빛에 탐) · 해골 궁수(화살) · 폭탄몬(다가와 터짐, 블록 파괴)
  - 상태 기반 AI: 대기 → 돌아다님 → 발견(벽 너머는 못 봄) → 길찾기로 추적 → 공격 → 놓치면 제자리로
- **1인칭 손**: 걷기 · 달리기 · 점프 흔들림, 캐기 · 공격 · 놓기 동작, 먹기. 든 도구 · 블록이 손에 입체로 보입니다.
- **무기**: 부활할 때마다 **칼 · M16 · 저격총 · 수류탄 3개**를 받습니다(죽어도 떨어뜨리지 않음).
  - 칼: 진짜 칼 모양(날 · 손잡이 · 가드). 한 번에 반 칸 → **20번** 찔리면 죽음. 클릭 = 베기, 꾹 = 연속 찌르기
  - 총: 몸에 **10발** 맞으면 죽음, **머리에 맞으면 한 발**에 죽음(헤드샷). 총알 **M16 90발(탄창 30 + 예비 60) · 저격총 30발(탄창 10 + 예비 20)**, R 로 재장전. 쏠 때마다 탄피가 튀어나와 바닥에 떨어짐(저격총은 노리쇠 당길 때). 오른쪽 아래에 **M16 90.30** 처럼 (남은 전체.탄창) 표시
  - 수류탄: 던지면 날아가 **땅에 떨어진 뒤 2초**에 터짐. 반경 5칸, 가까울수록 큰 피해(벽 뒤는 덜 아픔), 튕기며 굴러감. 던진 사람에게 킬
- **점수판**: 킬 · 데스 · 어시스트(죽기 10초 안에 같이 때린 사람). 킬하면 오른쪽 위에 알림. 서버가 켜져 있는 동안 집계됩니다.
- **동물**: 돼지 · 닭 · 소 · 양 · 늑대(무리 지어 다니고 하나를 때리면 무리가 덤빔). 돼지 → 돼지고기, 닭 → 닭고기, 늑대 → 늑대 가죽.
  고기를 먹으면 배고픔과 함께 **체력(하트)도 찹니다** (익힌 고기가 더 많이). 늑대 가죽 2장 → **늑대 가죽 옷**(몸 방어구, 방어력 7 · 내구도 400).
  - 저격총은 오른쪽 버튼을 누르면 스코프 줌, M16 은 조준 줌. 반동 · 총구 불꽃 · 탄 궤적 · 맞힘 표시(헤드샷은 빨강)
  - 동물 · 몹도 맞으면 움찔하고, 죽으면 부르르 떨다 옆으로 쓰러져 피를 흘리고 땅으로 꺼집니다.
  - 맞으면 피가 튀고 바닥에 핏자국이 남으며, 내 화면에도 피가 번집니다. 헤드샷 · 죽음은 더 크게 튑니다.
  - 벽 뒤에 숨은 사람은 맞지 않습니다. 맞았는지 · 머리인지 · 남은 탄은 서버가 판정합니다.
- **캐릭터 꾸미기**: 처음 로그인하면 '캐릭터 만들기' — 성별(남 · 여) · 옷(테크젠 흰 집업 · 남색 작업복) · 소매(긴팔 · 반팔) · 머리(남: 짧은 머리 · 가르마 · 스포츠 / 여: 단발 · 긴 머리 · 묶은 머리) · 머리색. 관리자는 **와이셔츠 · 검은 넥타이 · 검은 바지**도 고를 수 있습니다(서버가 권한 확인). 첫 화면 로그인 창 · 게임 시작 창 · 일시정지(Esc)에서 언제든 바꿀 수 있고, 같이 접속한 사람 화면에도 바로 바뀝니다.
- **멀티플레이**: 다른 사람 캐릭터(이름표, 방어구, 든 아이템), 서로 때리기(PvP, 맞으면 빨갛게 번쩍 · 체력 하트 감소, `/gamerule pvp false` 로 끄기), 걷기 · 웅크리기 · 휘두르기 동작, 블록 · 아이템 · 몹 · 전투 · 채팅 · 죽음/부활 동기화. 같은 블록을 동시에 캐거나 같은 아이템을 동시에 주워도 서버가 한 명에게만 줍니다.
- **설정**: 마우스 감도 · 시야 거리 · 시야각 · 밝기 · 소리 · 그래픽(고급/보통/저사양).

## 서버 권한 구조 (브라우저가 마음대로 못 바꿈)

- 인벤토리 조작은 브라우저가 먼저 보여 주고 서버가 같은 규칙(`shared/invops.js`)으로 다시 해서 확정합니다. 결과가 다르면 서버 정답으로 고칩니다.
- 체력 · 배고픔 · 경험치 · 죽음은 서버가 정합니다. 블록 캐기는 **캐는 시간까지 서버가 확인**하고, 놓기는 손에 그 블록이 있어야 합니다.
- 관리자 명령은 서버에서 계정 권한을 확인합니다.

## 명령어

| 명령 | 누가 | 설명 |
|---|---|---|
| `/help` `/spawn` `/kill` `/who` `/time` | 모두 | 도움말 · 스폰으로 · 다시 시작 · 접속자 · 지금 시간 |
| `/gamemode survival\|creative [이름]` | 관리자 | 게임 모드 |
| `/time day\|night\|noon\|midnight\|set 숫자` | 관리자 | 시간 |
| `/weather clear\|rain\|thunder` | 관리자 | 날씨 |
| `/give 아이템 [개수] [이름]` | 관리자 | 아이템 주기 (예: `/give 다이아몬드 10`) |
| `/tp 이름` · `/tp x y z` · `/tp 이름 x y z` | 관리자 | 이동 · 다른 사람 옮기기 |
| `/summon 몹 [마리]` | 관리자 | 몹 부르기 (예: `/summon 좀비 3`) |
| `/setspawn` · `/gamerule 규칙 true\|false` | 관리자 | 스폰 위치 · 규칙(keepInventory · mobGriefing · pvp) |
| `/say 공지` `/kick 이름` `/op` `/deop` `/status` `/save` `/backup` | 서버 관리자 | 공지 · 강제 퇴장 · 권한 · 상태 · 저장 · 백업 |

관리자 명령은 싱글플레이에서도 관리자만 쓸 수 있습니다. 관리자 추가: `config.json` 의 `admins` 에 아이디 추가 또는 관리자가 `/op 아이디`.

서버 창에서: `/list` · `/say 공지` · `/op 아이디` · `/passwd 아이디 새비밀번호`(비밀번호 잊었을 때) · `/save` · `/backup`

## 저장 · 백업

- `data/world.json` 멀티플레이 월드(시드 · 바뀐 블록 · 상자 · 화로 · 시간 · 날씨 · 규칙)
- `data/solo/*.json` 사람마다 싱글플레이 월드
- `data/accounts.json` 계정(비밀번호는 scrypt 해시) · 위치 · 인벤토리 · 방어구 · 체력 · 배고픔 · 경험치
- 30초마다 · 끌 때 자동 저장(임시 파일에 쓴 뒤 바꿔치기 → 쓰다 꺼져도 원본 보존), 10분마다 `data/backups/` 에 백업(24개 보관). 파일이 망가지면 최근 백업에서 자동으로 되살립니다.
- `data/` 는 git 에 올라가지 않습니다.
