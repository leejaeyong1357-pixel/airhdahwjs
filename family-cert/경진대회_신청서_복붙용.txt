■ 1. 제목

PDF OCR · 가족관계증명서 엑셀 정리


■ 2. 주요 기능

- 가족관계증명서 PDF·그림을 여러 개 한꺼번에 넣으면 본인/부/모/배우자/자녀를 사람별 묶음으로 엑셀에 정리
- 글자가 들어 있는 PDF와 스캔·캡처본을 쪽마다 자동으로 구분해 읽음 (다른 서류가 섞여 있어도 가족관계증명서 쪽만 골라냄)
- 스캔·캡처본은 사내 H Chat 모델 두 개가 각각 읽고, 줄 단위로 서로 대조
- 주민등록번호는 검증번호와 출생일 대조로 자동 검증하고, 틀렸을 가능성이 있는 칸은 "확인 필요"로 표시
- 줄마다 원본에서 잘라낸 그림을 옆에 보여줘서 바로 대조·수정 가능
- 사망, 외국인, 뒷자리 가려짐, 주민번호 없음 등을 비고에 자동 기재
- 설치 없이 압축만 풀면 실행되는 배포용 묶음 제공


■ 3. 설명

인사·총무 업무에서 직원이 제출한 가족관계증명서를 보고 가족 정보를 엑셀에 한 줄씩 옮겨 적는 작업을 자동화한 도구입니다.

파일을 넣고 "읽기 시작"을 누르면, 글자가 들어 있는 PDF는 글자를 그대로 꺼내고(토큰 사용 없음), 스캔본이나 화면 캡처는 사내 H Chat에 보내 표를 보이는 그대로 옮겨 적게 합니다. 이때 서로 다른 두 모델이 따로 읽은 결과를 줄 단위로 맞대어, 값이 다르거나 검증번호를 통과하지 못한 칸은 사람이 확인하도록 표시합니다. AI가 읽은 값을 그대로 믿지 않고 검증 단계를 한 번 더 거치는 것이 핵심입니다.

결과는 사람(본인)마다 한 묶음으로 정리된 시트와, 필터·정렬용 한 줄 목록 시트 두 가지로 엑셀에 저장됩니다. 주민등록번호 뒷자리 가리기, 포함할 가족 범위 선택도 가능합니다.

개인정보 보호를 위해 프로그램은 각자 PC 안에서만 실행되고 다른 PC에서 접속할 수 없습니다. 글자 PDF는 외부로 전송하지 않으며, H Chat을 켠 경우에만 스캔·캡처 쪽의 그림이 사내 H Chat으로 전송됩니다. H Chat 없이 PC 안의 오픈소스 글자 인식만으로도 동작합니다.


■ 4. 사용한 AI · 기술 · 스택 · 알고리즘 · 아키텍처

[AI]
- H Chat API: Claude Sonnet 5.5(주 판독) + GPT-5.5(교차 확인) — 문서 그림을 읽어 표를 JSON으로 옮겨 적음
- 오픈소스 OCR: Tesseract.js(한국어), PaddleOCR PP-OCRv4 인식 모델(ONNX Runtime Web) — H Chat 없이도 PC 안에서 동작

[기술 스택]
- Node.js(외부 라이브러리 없는 로컬 서버), 순수 JavaScript 웹 화면
- pdf.js(PDF 글자 추출·그리기), ExcelJS(엑셀 생성), WebAssembly

[알고리즘]
- 쪽 판별: PDF 글자 정보 유무와 쪽 전체 그림 여부로 글자 PDF/스캔본 자동 구분
- 그림 전처리: 적응형 흑백화, 기울기 보정, 표 선 검출로 표 위치·줄·칸 자동 분할
- 다중 판독 대조: 두 AI 모델(+로컬 OCR)의 결과를 줄 단위로 맞대어 일치 여부 판정
- 검증: 주민등록번호 검증번호, 출생일↔앞 6자리, 성별·출생 세기↔뒷자리 첫 숫자, 구분 순서, 가족 간 성씨 대조

[아키텍처]
- 브라우저 안에서 파일을 처리하고 로컬 서버는 화면 제공과 H Chat 중계만 담당
- 로컬 서버는 자기 PC에서만 접속 가능(127.0.0.1), 화면에서 외부로 직접 전송 차단(CSP)
- API 키는 서버 메모리에만 보관(선택 시 해당 PC에만 저장)


■ 5. 기대 효과

- 증명서를 보고 엑셀에 손으로 옮겨 적던 반복 작업을 "파일 넣기 → 확인 → 엑셀 받기"로 단축
- 주민등록번호 오입력 방지: 검증번호와 출생일 대조로 틀린 번호를 자동으로 걸러내고, 의심되는 칸만 사람이 확인
- 담당자는 전체를 다시 입력하는 대신 "확인 필요"로 표시된 줄만 원본 그림과 대조하면 됨
- 글자 PDF는 토큰을 쓰지 않고 즉시 처리되어 비용 부담이 적음
- 설치 없이 배포할 수 있어 다른 부서·담당자도 바로 사용 가능
- 같은 구조(문서 판독 → 다중 모델 대조 → 규칙 검증 → 엑셀)를 다른 증명서·서류 정리에 확장 가능
