# 가족관계증명서 → 엑셀 정리

가족관계증명서 PDF(여러 개 가능)를 넣으면 **본인 / 부 / 모 / 배우자 / 자녀**를 사람별 묶음으로 정리해 엑셀로 내려주는 도구입니다.

- **이 PC 안에서만** 처리합니다. 증명서는 서버로 올라가지 않고 브라우저 안에서만 읽습니다. (화면이 인터넷으로 자료를 보낼 수 없게 막아 두었습니다)
- **기본은 AI 토큰을 쓰지 않습니다.** 글자 인식도 PC 안에서 돕니다. (H Chat 보조 판독을 켰을 때만 예외 — 아래 참고)
- 주소: `http://localhost:2824` (다른 PC에서는 접속할 수 없습니다)

## 실행

`start.cmd` 를 더블클릭합니다. 처음 한 번은 필요한 파일을 내려받느라 1~2분 걸립니다(인터넷 필요). 그다음부터는 인터넷 없이도 됩니다.

## 쓰는 법

1. PDF(또는 JPG·PNG)를 끌어다 놓습니다. 여러 개를 한꺼번에 넣어도 되고, 다른 서류가 섞인 PDF는 가족관계증명서 쪽만 골라 읽습니다.
2. 결과 화면에서 **줄마다 원본에서 잘라낸 그림**과 읽은 값을 견주어 봅니다. 틀린 칸은 바로 고칩니다.
3. 빨간 "확인 필요" 줄은 꼭 보고, 맞으면 "원본과 맞는지 확인했어요"에 체크합니다.
4. **엑셀 받기**를 누릅니다.

### 읽는 방식

| 방식 | 설명 |
|---|---|
| 자동 (기본) | 글자가 들어 있는 PDF는 글자를 그대로 꺼내고(가장 정확·빠름), 스캔본은 글자 인식(OCR)으로 읽습니다. 쪽마다 알아서 판별합니다. |
| 전부 스캔 방식 | 모든 쪽을 그림으로 보고 글자 인식으로 읽습니다. 글자가 깨져 나오는 PDF일 때 씁니다. |

스캔본은 한자(이름 한자·본)를 읽지 않습니다. 한자·본 칸은 글자 PDF에서만 채워집니다.

### 스스로 검증하는 것

- 생년월일 ↔ 주민번호 앞 6자리 일치
- 주민번호 검증번호(2020년 10월 이전 출생), 출생 세기·성별 ↔ 뒷자리 첫 숫자
- 스캔본: 같은 칸을 여러 번 읽어 값이 다르면 표시, 성씨가 아닌 첫 글자·드문 글자 표시, 가족 간 성 대조, 구분 순서(본인→부→모→배우자→자녀) 대조
- 표 선이 흐려 줄 위치를 추정한 경우 표시

### 비고에 자동으로 적히는 것

`사망` · `외국인` · `뒷자리 가려짐` · `생년월일 없음` · `주민번호 없음` · `생년월일·주민번호 없음` · `확인 필요: (사유)`

## 화면 캡처 그림을 넣을 때

PDF 원본이 가장 정확합니다. 캡처 그림(PNG·JPG)도 읽지만 **글자가 작을수록 틀립니다.**

- 도구가 그림 안에서 표를 찾아 그 부분만 원본 크기로 키워 읽습니다.
- 캡처할 때는 PDF를 **화면 폭에 맞춰 크게 확대**한 뒤, 표 전체(제목~맨 아래 줄)가 들어가게 찍어 주세요. "쪽 전체 보기"로 작게 찍으면 숫자를 틀립니다.
- 모니터를 휴대폰으로 찍은 사진은 권하지 않습니다.

## H Chat 보조 판독 (선택)

스캔·캡처로 읽은 줄 가운데 **확인 필요한 줄**(또는 스캔 줄 전부)의 그림을 사내 H Chat에 보내 한 번 더 읽게 하고, 이 PC에서 읽은 값과 대조합니다. 기본은 **꺼짐**입니다.

- 켜면 **그 줄의 그림(이름·주민등록번호 포함)이 사내 H Chat으로 전송**되고 토큰을 씁니다(줄당 수백 토큰). 회사 개인정보 처리 기준에 맞는지 먼저 확인하세요. 글자 PDF로 읽은 줄은 보내지 않습니다.
- 화면의 "H Chat 보조 판독"을 펼쳐 주소·호출 형식·모델·API 키를 넣고 **연결 테스트**를 누릅니다. 그림을 읽을 수 있는 모델(예: gpt-4o 계열)이어야 합니다.
- API 키는 기본으로 프로그램이 켜져 있는 동안만 기억합니다. "이 PC에 키 저장"을 고르면 `data/hchat.json`에 저장됩니다(깃허브에 올라가지 않는 폴더, 암호화되지 않음).
- AI 값도 그대로 믿지 않습니다.
  - 숫자: 생년월일↔주민번호 맞물림과 검증번호를 **통과하는 쪽**을 씁니다. 이 PC에서 읽은 값이 이미 검증을 통과했으면 AI가 달라도 바꾸지 않습니다.
  - 이름: 두 판독이 같으면 확인된 것으로 봅니다. 한두 글자만 다르면 H Chat 값을 쓰되 "다름" 표시를 남깁니다. 전혀 다르면 바꾸지 않고 표시만 합니다.
  - 한자·본: 스캔본은 H Chat이 읽은 값으로 채웁니다(대조할 짝이 없어 확인 필요).
- 실제 H Chat과의 연결은 개발 환경에서 확인하지 못했습니다(가짜 서버로만 시험). 주소·호출 형식·모델 이름은 H Chat API 안내서에 맞춰 바꿔야 할 수 있습니다.

## 엑셀 모양

- **가족관계** 시트: 사람(본인)마다 한 묶음, 묶음 사이 빈 줄.
- **목록(필터용)** 시트: 한 줄에 한 사람, 본인 이름 칸 포함, 필터 켜짐.

## 정확도 (가짜 견본으로 잰 값)

| 종류 | 결과 |
|---|---|
| 글자 PDF (3명 18줄) | 모든 칸 정답 |
| 보통 품질 스캔 (4명 21줄) | 126칸 중 1칸 틀림 — 외국인 이름의 드문 글자 "옌"→"엔", 확인 표시됨 |
| 나쁜 조건 스캔 (150dpi 흑백 · 120dpi · 2도 기울어짐 · 짙은 바탕무늬+잡티) | 288칸 중 9칸 틀림, **틀린 칸은 모두 확인 표시됨** |
| 화면 캡처 그림 4종 (폭 맞춤·보통·잘라내기·쪽 전체 보기) | 126칸 중 4칸 틀림(3칸은 글자가 가장 작은 "쪽 전체 보기"), 모두 확인 표시됨 |

스캔본의 **이름**은 글자 인식 특성상 100%가 될 수 없습니다. 숫자는 서로 대조해 걸러내지만 이름은 대조할 짝이 없으니, 줄 위 그림과 한 번씩 견주어 보세요.
모니터를 휴대폰으로 찍은 사진은 표 선이 뭉개져 정확도가 많이 떨어집니다. PDF 원본을 넣어 주세요.

## 주의

- 실제 증명서 PDF와 결과 엑셀은 깃허브에 올리지 마세요. 이 폴더의 `.gitignore`가 PDF·엑셀·그림을 막아 두었습니다(`sample/견본_*.pdf` 가짜 견본만 예외).
- 회사 보안(DRM)이나 암호가 걸린 PDF는 열 수 없습니다. 보안을 해제한 뒤 넣어 주세요.
- `sample/` 의 견본은 양식만 흉내 낸 가짜입니다(실존 인물·번호 아님).
