# 가족관계증명서 → 엑셀 정리

가족관계증명서 PDF(여러 개 가능)를 넣으면 **본인 / 부 / 모 / 배우자 / 자녀**를 사람별 묶음으로 정리해 엑셀로 내려주는 도구입니다.

- **이 PC 안에서만** 처리합니다. 증명서는 서버로 올라가지 않고 브라우저 안에서만 읽습니다. (화면이 인터넷으로 자료를 보낼 수 없게 막아 두었습니다)
- **기본은 AI 토큰을 쓰지 않습니다.** 글자 인식도 PC 안에서 돕니다. ("H Chat으로 읽기"를 켰을 때만 예외 — 아래 참고)
- 주소: `http://localhost:2824` (다른 PC에서는 접속할 수 없습니다)

## 실행

`start.cmd` 를 더블클릭합니다. 처음 한 번은 필요한 파일을 내려받느라 1~2분 걸립니다(인터넷 필요). 그다음부터는 인터넷 없이도 됩니다.

## 쓰는 법

1. PDF(또는 JPG·PNG)를 끌어다 놓습니다. 여러 개를 한꺼번에 넣어도 되고, 다른 서류가 섞인 PDF는 가족관계증명서 쪽만 골라 읽습니다.
2. 결과 화면에서 **줄마다 원본에서 잘라낸 그림**과 읽은 값을 견주어 봅니다. 틀린 칸은 바로 고칩니다.
3. 빨간 "확인 필요" 줄은 꼭 보고, 맞으면 "원본과 맞는지 확인했어요"에 체크합니다.
4. **엑셀 받기**를 누릅니다.

### 읽는 방식

| 방식 | 설명 |
|---|---|
| 자동 (기본) | 글자가 들어 있는 PDF는 글자를 그대로 꺼내고(가장 정확·빠름), 스캔본은 글자 인식(OCR)으로 읽습니다. 쪽마다 알아서 판별합니다. |
| 전부 스캔 방식 | 모든 쪽을 그림으로 보고 글자 인식으로 읽습니다. 글자가 깨져 나오는 PDF일 때 씁니다. |

스캔본은 한자(이름 한자·본)를 읽지 않습니다. 한자·본 칸은 글자 PDF에서만 채워집니다.

### 스스로 검증하는 것

- 문서의 출생일 ↔ 주민번호 앞 6자리 일치 (출생일은 대조에만 쓰고, 엑셀에는 옵션을 켰을 때만 넣습니다)
- 주민번호 검증번호(2020년 10월 이전 출생), 출생 세기·성별 ↔ 뒷자리 첫 숫자
- 스캔본: 숫자 칸은 두 가지 오픈소스 엔진(Tesseract · PaddleOCR 인식 모델)으로 읽어 검증을 통과하는 값을 고름. 같은 칸을 여러 번 읽어 값이 다르면 표시, 성씨가 아닌 첫 글자·드문 글자 표시, 가족 간 성 대조, 구분 순서(본인→부→모→배우자→자녀) 대조
- 표 선이 흐려 줄 위치를 추정한 경우 표시

### 비고에 자동으로 적히는 것

`사망` · `외국인` · `뒷자리 가려짐` · `주민번호 없음` · `확인 필요: (사유)`

## 화면 캡처 그림을 넣을 때

PDF 원본이 가장 정확합니다. 캡처 그림(PNG·JPG)도 읽지만 **글자가 작을수록 틀립니다.**

- 도구가 그림 안에서 표를 찾아 그 부분만 원본 크기로 키워 읽습니다.
- 캡처할 때는 PDF를 **화면 폭에 맞춰 크게 확대**한 뒤, 표 전체(제목~맨 아래 줄)가 들어가게 찍어 주세요. "쪽 전체 보기"로 작게 찍으면 숫자를 틀립니다.
- 모니터를 휴대폰으로 찍은 사진은 권하지 않습니다.

## H Chat으로 읽기 (선택)

스캔·캡처 쪽의 그림을 사내 H Chat에 보내 **표를 보이는 그대로 옮겨 적게** 합니다. 기본은 **꺼짐**입니다. 캡처 그림처럼 이 PC의 글자 인식이 약한 자료에 씁니다.

### 켜는 법

1. 화면의 "H Chat으로 읽기"를 펼칩니다.
2. API 키를 붙여 넣습니다. (프로젝트 키라면 Project ID도 넣습니다. 개인 키는 비워 둡니다.)
3. **연결 테스트**를 누릅니다. 통신 확인 → 각 모델이 시험 그림의 숫자를 읽어 오는지 확인하고, 통과하면 자동으로 켜집니다.
4. 파일을 넣습니다.

인증서 오류가 나오면 "인증서 검증 건너뛰기"를 켭니다(안내서의 `curl -k`와 같은 뜻).
안내서대로 환경 변수 `H_CHAT_API_KEY` · `H_CHAT_API_PROJECT_ID` · `H_CHAT_API_MODEL`을 잡아 두었다면 그 값이 처음 값으로 들어갑니다.

### 모델

| 칸 | 기본값 | 역할 |
|---|---|---|
| 주 판독 모델 | `claude-sonnet-5-5` | 표를 옮겨 적는 모델 |
| 교차 확인 모델 | `gpt-5.5` | 다른 회사 모델로 한 번 더 읽어 줄 단위로 견줌 (비우면 안 씀 → 토큰 절반) |

두 모델 모두 목록에서 바꿀 수 있습니다. 어느 모델이 이 서류를 가장 잘 읽는지는 개발 환경에서 재 보지 못했습니다(H Chat에 접속할 수 없음). 그래서 **서로 다른 회사의 상위 모델 둘이 같은 값을 읽었는지**로 확인하는 방식을 기본으로 했습니다.

### 호출 형식 (H Chat API 명세 기준)

| 모델 | 주소 |
|---|---|
| Claude | `{base}/v3/claude/messages` |
| GPT-5 이상 | `{base}/v3/openai/responses` (안 되면 `{base}/v3/openai/deployments/{model}/chat/completions`) |
| Gemini | `{base}/v3/models/{model}:generateContent` |

머리글은 `Authorization: Bearer {키}` (프로젝트 키면 `X-Project-Id` 추가). 명세에 "원래 API와 다를 수 있다"고 되어 있어, 요청이 400으로 거절되면 흔한 차이(토큰 수 이름, `anthropic_version` 등)를 바꿔 한 번 더 시도합니다.

### AI가 읽은 값도 그대로 믿지 않습니다

- **주민번호**: 출생일 칸과 앞 6자리가 맞물리고 검증번호를 통과하는 값을 씁니다. 검증번호 대상이 아닌 번호(2020년 10월 이후 출생·외국인)는 두 판독이 같아야 통과하고, 한 번만 읽었으면 "확인 필요"가 붙습니다.
- **이름·구분·성별**: 두 모델이 같으면 통과, 다르면 주 모델 값을 쓰고 "판독이 서로 다름"을 표시합니다.
- 모델이 못 읽은 자리는 `?`로 답하게 했고, 그런 줄은 표시됩니다.
- 줄 수가 판독마다 다르면 모든 줄에 표시됩니다.
- 이 PC의 글자 인식 결과도 세 번째 판독으로 함께 견줍니다.

### 알아둘 것

- 켜면 **스캔·캡처 쪽의 그림 전체(이름·주민등록번호·등록기준지 포함)가 사내 H Chat으로 전송**되고 토큰을 씁니다(쪽당 대략 수천 토큰, 교차 확인을 쓰면 두 배). 회사 개인정보 처리 기준에 맞는지 먼저 확인하세요. 글자가 들어 있는 PDF는 보내지 않습니다.
- API 키는 기본으로 프로그램이 켜져 있는 동안만 기억합니다. "이 PC에 키 저장"을 고르면 `data/hchat.json`에 저장됩니다(깃허브에 올라가지 않는 폴더, 암호화되지 않음).
- **실제 H Chat과의 연결은 개발 환경에서 확인하지 못했습니다**(명세의 주소대로 만든 가짜 서버로 시험). 연결 테스트가 실패하면 화면에 나오는 오류 문구를 그대로 알려 주세요.

## 엑셀 모양

- **가족관계** 시트: 사람(본인)마다 한 묶음, 묶음 사이 빈 줄.
- **목록(필터용)** 시트: 한 줄에 한 사람, 본인 이름 칸 포함, 필터 켜짐.

## 정확도 (가짜 견본으로 잰 값)

| 종류 | 결과 |
|---|---|
| 글자 PDF (3명 18줄) | 모든 칸 정답 |
| 보통 품질 스캔 (4명 21줄) | 126칸 중 1칸 틀림 — 외국인 이름의 드문 글자 "옌"→"엔", 확인 표시됨 |
| 나쁜 조건 스캔 (150dpi 흑백 · 120dpi · 2도 기울어짐 · 짙은 바탕무늬+잡티) | 288칸 중 8칸 틀림, **틀린 칸은 모두 확인 표시됨** |
| 화면 캡처 그림 4종 (폭 맞춤·보통·잘라내기·쪽 전체 보기) | 126칸 중 3칸 틀림, 모두 확인 표시됨 |

위 값은 H Chat을 끄고 이 PC의 글자 인식만으로 잰 것입니다.

스캔본의 **이름**은 글자 인식 특성상 100%가 될 수 없습니다. 숫자는 서로 대조해 걸러내지만 이름은 대조할 짝이 없으니, 줄 위 그림과 한 번씩 견주어 보세요.
모니터를 휴대폰으로 찍은 사진은 표 선이 뭉개져 정확도가 많이 떨어집니다. PDF 원본을 넣어 주세요.

## 주의

- 실제 증명서 PDF와 결과 엑셀은 깃허브에 올리지 마세요. 이 폴더의 `.gitignore`가 PDF·엑셀·그림을 막아 두었습니다(`sample/견본_*.pdf` 가짜 견본만 예외).
- 회사 보안(DRM)이나 암호가 걸린 PDF는 열 수 없습니다. 보안을 해제한 뒤 넣어 주세요.
- `sample/` 의 견본은 양식만 흉내 낸 가짜입니다(실존 인물·번호 아님).

## 개발

```
npm install
```
