# 현장밀착점검 보고서 (일일현장안전점검) — 비즈니스솔루션팀 김소진 매니저 버전

PT생산실 버전(`pt-report`, 포트 2822)과 같은 기능을 따로 쓰는 복사본입니다. 기본 문구만 비즈니스솔루션팀 · 김소진 매니저로 바꿨고, 포트는 **2823** 입니다. 한 PC 에서 두 페이지를 같이 켜도 됩니다.

KOI 에 올리기엔 파일이 커서, 링크 한 줄로 실장님들이 들어와 월별 파일을 내려받게 하는 페이지입니다.
다른 폴더(blockcraft · edu-survey · kpi · pt-report)와는 별개입니다. Node.js 만 있으면 되고 설치할 것은 없습니다.

## 켜기
- Windows: `bs-report\start.cmd` 더블클릭 (또는 `cd bs-report` → `node server.js`)
- 포트: **2823** (바꾸려면 `set PORT=다른번호` 후 실행)
- 보는 주소: `http://<이 PC IP>:2823/` — 켜면 창에 주소가 나옵니다. 이 주소를 KOI 에 링크로 올리면 됩니다.
- 다른 PC 에서 안 열리면 방화벽에서 2823 포트를 허용하세요.

## 관리자 화면
- 보는 화면 **맨 아래 오른쪽 톱니바퀴** → `http://<이 PC>:2823/admin`
- 처음 비밀번호: 서버를 켤 때 창에 나오고 `bs-report/data/admin-password.txt` 에도 있습니다. [설정]에서 꼭 바꾸세요.
- 왼쪽 메뉴
  - **현황**: 오늘 접속 · 오늘 다운로드 · 받아 간 사람 · 올린 파일 수, 최근 다운로드(누가 · 무엇 · 언제), 월별 자료 상태, KOI 에 올릴 링크 복사
  - **파일 관리**: 월별 칸에 파일을 끌어다 놓거나 [파일 올리기] — 어떤 파일이든, 큰 파일(기본 최대 2GB)도 진행 막대와 함께. 칸 제목 · 보일 파일 이름은 눌러서 바로 고치고, ⠿ 를 끌어 순서를 바꿈. 칸 추가 · 삭제, 한 줄에 칸 수
  - **문구 편집**: 머리글 · 인사말 · 자료 칸 · 아래 안내의 모든 문구. 고치는 대로 오른쪽 미리보기에 바로 보임
  - **접속 · 다운로드 기록**: 아래 참고
  - **설정**: 보는 화면 주소 복사, 이름 묻기 켜기/끄기, 머리글 사진, 비밀번호, 문구 초기화
- 고친 내용이 있으면 아래에 [저장하기] 띠가 뜹니다. 저장하면 보는 화면에 바로 반영됩니다. (파일 올리기 · 지우기는 바로 반영)

## 접속 · 다운로드 기록
- 처음 들어온 사람에게 **이름 · 소속(선택)** 을 한 번 묻습니다 (그 PC 브라우저에 기억, 왼쪽 아래에서 바꾸기 가능). 관리자 화면에서 끌 수 있습니다.
- 남는 것: **언제(초 단위) · 누가(이름 · 소속) · 무엇(접속 / 어떤 달 어떤 파일 다운로드)** + 접속한 PC 의 IP · PC 이름(사내 DNS 가 알려 주면) · 브라우저. 관리자 로그인 · 비밀번호 틀림도 남습니다.
- 서버 창에도 한 줄씩 바로 뜹니다. 예: `[2026. 11. 5. 오전 9:12:03] 다운로드 — 홍길동(생산1팀 실장) · 10.1.2.34 (PT-PC07) · 1월 일일현장안전점검.pptx`
- 관리자 화면 [접속 · 다운로드 기록]: 다운로드 / 접속 / 전체 / 관리자 · 오늘 / 7일 / 30일 / 전체 기간으로 걸러 보기, 이름 · 파일 · IP 로 찾기, 사람별(다운로드 · 접속 횟수 · 받은 파일 · 마지막) · 파일별(횟수 · 받은 사람) 요약, 엑셀(CSV) 내려받기
- 파일: `bs-report/data/access-log.jsonl` (지워지지 않고 계속 쌓임)

## 저장 위치
- 설정: `bs-report/data/site.json` · 올린 파일: `bs-report/data/files/` (git 에 올라가지 않음 — 이 PC 에만)
- 내려받을 때 파일 이름은 “1월 일일현장안전점검.pptx” 처럼 칸 제목이 앞에 붙습니다.
- 최대 파일 크기를 바꾸려면 `set MAX_UPLOAD_MB=5000` 후 실행.
