# AX 버디 — 화면 위 캐릭터 비서 (H Chat 기반)

모니터 위에 떠 있는 작은 캐릭터입니다. 다른 폴더(blockcraft · edu-survey · pt-report · bs-report · kpi)와는 별개인 **윈도우용 프로그램**(Electron)입니다.

## 지금 되는 것 (1단계)
- **화면 위 캐릭터**: 항상 위에 떠 있고, 끌어서 옮기고, 누르면 대화창이 열립니다. 5분 조용하면 좁니다. 작업 표시줄 오른쪽 아이콘(트레이)에서 숨기기 · 끝내기.
- **처음 실행**: ① H Chat API 키 (환경: 운영 · 검증 · 개발, [연결 시험]) ② 캐릭터 (기본 AI 봇 / 내 사진 등록)
- **대화**: H Chat 으로 답합니다 (사내 인증서 · 프록시는 윈도우 설정을 그대로 씁니다).
- **일정 알림**: “오늘 11시에 회의”, “내일 오후 2시 반 주간회의 잡아줘”, “30분 뒤에 전화”, “다음주 월요일 오전 10시 주간보고” → 어떻게 알아들었는지 되말해 주고, **10분 전**과 정각에 말풍선 + 윈도우 알림. 잘못 알아들었으면 바로 취소. [일정] 탭에서 목록 · 지우기.
- **파일 먹기**: 파일을 캐릭터에게 끌어다 놓으면 입 벌리기 → 먹기 → 씹기 → 무엇으로 바꿀지 고르기 → 진행 막대 → 뱉기 → “어디에 저장할까요?”(윈도우 저장 창)
  - 그림(JPG · PNG) → **PDF**, **AI**(일러스트레이터에서 열리는 형식 — 그림이 그대로 담김, 선 따기는 아님)
  - PPT → PDF, PDF → PPT · Word, Word → PDF, 한글 → PDF 는 버튼만 보이고 “다음 업데이트” (2단계)
- **보안 문서**: 암호화(DRM)되어 열 수 없는 파일을 먹이면 “보안 해제해 주세요!” 하고 알려 줍니다.
- API 키는 윈도우 계정으로 암호화해 그 PC 에만 저장합니다 (코드 · 깃허브에는 들어가지 않음).

## 아직 안 된 것
- 사진 → 애니메이션풍 캐릭터 (H Chat 의 그림 생성 기능 확인 필요 — 지금은 사진을 등록해도 기본 봇으로 보임)
- 오피스 · 한글 변환, 오타 찾기, Teams 회의록

## 실행 (개발용)
1. Node.js LTS 설치
2. `ax-buddy\start.cmd` 더블클릭 — 처음 한 번은 필요한 파일(Electron)을 내려받습니다.

## 전사 배포용 설치 파일 만들기
`cd ax-buddy` → `npm install` → `npm run dist` → `ax-buddy\dist\AX 버디 Setup x.y.z.exe`
- 설치하면 PC 를 켤 때 자동으로 시작합니다 (설정에서 끌 수 있음).
- 서명되지 않은 설치 파일은 윈도우가 경고를 띄울 수 있습니다. 전사 배포 때는 회사 코드 서명 인증서로 서명하는 것을 권합니다.

## H Chat 연결 설정
- 기본 주소: 운영 `https://internal-apigw-kr.hmg-corp.io/hchat-in/api`
- 호출 형식 기본값은 Azure OpenAI 형식(`/openai/deployments/{모델}/chat/completions`, 헤더 `api-key`)입니다. **API 가이드의 실제 경로 · 모델 이름과 다르면** 설정의 [호출 형식] · [호출 경로] · [모델 이름]을 바꾸고 [연결 시험]으로 확인하세요.

## 시험
- `npm test` — 일정 문장 해석, 알림 시각, 파일 규칙 · 보안 문서 감지, 그림 → PDF, H Chat 호출 형식 · 오류 안내
- 화면 흐름(설정 → 대화 → 일정 → 알림 → 파일 먹기 → 저장)은 가짜 H Chat 서버로 리눅스에서 자동 시험했습니다.
- **윈도우 실제 PC 에서 확인이 필요한 것**: 투명한 부분 뒤 화면 클릭(창 모양), 탐색기에서 파일 끌어다 놓기, 윈도우 알림, API 키 암호화 저장, 자동 시작, 실제 H Chat 연결

## 구조
- `main.js` 창 · 트레이 · 알림 · 저장 · H Chat 호출 / `preload.js` 화면에 넘기는 기능
- `src/schedule.js` 일정 해석 · 알림 / `src/convert.js` 변환 규칙 · 보안 문서 감지 · 그림 → PDF / `src/hchat.js` H Chat 호출
- `renderer/` 캐릭터(SVG) · 말풍선 · 대화 · 설정 화면
